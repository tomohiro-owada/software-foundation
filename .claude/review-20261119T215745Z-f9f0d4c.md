## 指摘

### 1. 証拠の訂正元を記録する欄が証拠台帳にない（軽微）

- 対象: `spec/protocols.md:21`、`schemas/run.schema.json`（`証拠` の要素）
- 根拠: 仕様は、訂正後の証拠に別の ID を付けたうえで、訂正元の ID、取得時点、訂正された項目をたどれるようにすると定めている。しかし証拠の要素は12項目に固定されており（`additionalProperties: false`）、訂正元の ID や訂正項目を書く欄がない。今の形では、`制約` や `結果` などの自由記述の欄に書くしかない。
- 影響: 訂正元をたどれるかを、記録の構造に基づいて確かめられない。確認手順（`examples/validation.md:187`）の「旧裁定の参照先から当時の判断を再現し、訂正後の証拠から再評価する」を機械的に照合するには、訂正元の参照が必要になる。訂正元の ID が台帳に存在するかも、既存の参照検査の対象外になる。
- 修正案: 証拠に任意欄 `訂正元`（訂正元の証拠ID、訂正された項目、訂正の時点）を追加する。あわせて、参照先が台帳に存在しない事例を、構造は適合・意味は不適合として確認データに加える。
